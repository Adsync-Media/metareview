## Problem

`fsm init` stores every run under the **main** worktree's `.metareview/runs/`, while `review record-lenses --from-run` looked for the run under the **current** worktree. From a linked worktree, registration therefore failed with `no such FSM run under .metareview/runs/` for a run the FSM had just created, and the only workaround was copying the audit between worktrees.
